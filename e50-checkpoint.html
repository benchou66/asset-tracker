年度檢核表(每年 12/15 決策日對照)
判讀:實際 ≥ E50 路徑 → E50 在軌(2031 提前退劇本活著);介於兩線之間 → E50 落後、基準劇本(2033 達標)仍在軌;低於 11.8% 線 → 雙雙落後,回歸 v3 本則時程。單一年份偏離 ±15% 屬正常波動,連續兩個檢核日落後才有意義。
E50 檢核點:2026/12/31 加權指數須站上 50,000(等速路徑年底約 47,300,站上 50,000 代表超前);未達 → E50 作廢(手冊規則)。門檻 3,333 萬與目標 3,482 萬在手冊為「引擎」口徑,本圖用庫存總市值方便對帳,兩者差約 = 防禦部位市值(今日約 107 萬),判讀時實際數字可先減去防禦部位再比目標線。
如何每年更新
用文字編輯器打開本檔,找到 const ACTUALS,照格式加一行當日庫存總市值(建議每年 12/15 決策日與 6/30 各記一筆),存檔重開即可。歷史紀錄都保留在檔案裡,圖與檢核表會自動重算。

本圖為教育性推算(等速路徑為中位劇本時間表,非保證),非個人化投資建議。E50 為手冊 v3 附錄八之參考情境;規則修訂僅得於 5 年檢視點進行。
